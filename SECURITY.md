# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability in Securebox, please report it responsibly. 

## Our Approach to Security
Securebox is built with security at its core:
- **No Execution**: We never execute untrusted code from scanned repositories.
- **Secret Management**: We use strict environment variable management and avoid hardcoding credentials.
- **Controlled Fixes**: AI-generated fixes are designed to be reviewed and verified before application.
